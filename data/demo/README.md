# Margin Guardian: demo data

Everything here is **invented**: the shop, the suppliers, the prices and the sales. No real company or customer data.

**The shop**: *Rideline Cycles*, a small online bike-accessories store selling in EUR. 50 products from 3 suppliers.

| File | What it is |
|---|---|
| `catalog.csv` | The shop's catalog: SKU, name, supplier code, unit cost (EUR), retail price, average monthly units |
| `sales_history.csv` | 24 months of sales per SKU (Oct 2024 to Sep 2026), with seasonality, past price changes and short promotions. Generated by `scripts/make_demo_sales.py` (fixed seed) |
| `competitor_prices.csv` | Prices of 3 fictional competitors for about 60% of the products |
| `suppliers/old/` | The previous price list of each supplier |
| `suppliers/new/` | The new price list of each supplier, with hidden changes |

**The suppliers**, each with its own format:
- **VeloParts GmbH** (DE): clean PDF table, German/English descriptions, EUR.
- **Ciclo Componenti Srl** (IT): messier PDF, Italian, prices like `€ 18,50`, grouped by category, with footnotes.
- **TrailGear Ltd** (UK): Excel, prices in **GBP**, some items priced **per pack**, not per unit.

Demo assumption: 1 GBP = 1.17 EUR (fixed).

Supplier descriptions do not match the catalog names (different language and wording): matching them is part of the job.
